The given program consists of a sql database, a fastAPI program and a python program.
In order for a person to run this program on Linux, Mac or Windows, the following requirements have to be met:
1. Python must be installed, version 3.9 or higher
2. FastAPI must be installed

Once you have confirmed that both Python and FastAPI are installed, please proceed with the following:
1. Open terminal and enter any folder where you normally work in.
2. Please type:
git clone https://github.com/MaximeLegit/book-club-library_duo.git


After these steps, in order to run this open_library program, one has to open main.py file.
Once this is done, please run the main.py file, via terminal or via your editor. It will create an -env file for you,
and it will run the program.

The Program:

Currently, this program is input based, hence, please attempt to follow the questions and provide corresponding
inputs. Alternatively, you can also perform same operation(s) via fastAPI. In our case, probably as is many other
cases, the webpage to open in your desired browser is: http://127.0.0.1:8000/docs#/. Once you are on that page,
you have the possibility to perform operations directly on our database, such as get_books, get_book, update_book,
delete_book etc. Once more, the FastAPI is input based as well, therefore, attempt to do your best to follow the
instructions/input.

Observations: We have tested many scenarios and the program did not crash. Hopefully, it will not crash for you either,
since this is one of the core requirements for the program.
